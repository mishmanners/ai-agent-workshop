## Step: Your Mission

You will build an AI Agent who remembers you across different communication channels including: SMS, Voice, and Webchat with shared memory using [Twilio Agent Connect (TAC)](https://www.twilio.com/docs/conversations/agent-connect), [OpenAI](https://developers.openai.com/api/reference/responses/overview), and FastAPI.

## Step: Prerequisites 

Make sure you have your accounts and local tools ready before we start the workshop.

1. [GitHub Account](https://github.com/) — create one at github.com
2. Code Editor of choice — for example, [VS Code](https://code.visualstudio.com/)
3. [Git](https://git-scm.com/install/windows) — the command line tool that can be installed from git-scm.com
4. [GitHub CLI](https://cli.github.com/) — optional if you'd like to use GitHub commands from your termianl
5. [Python 3.10](https://www.python.org/downloads/) or newer — already installed if you are reading this in the browser
6. [OpenAI API key](https://platform.openai.com/api-keys) — create one at platform.openai.com
7. [ngrok](https://ngrok.com) or another HTTPS tunnel — needs to be installed and able to forward to port 8000
