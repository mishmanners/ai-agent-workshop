## Step: Your Mission

You will build an AI Agent who remembers you across different communication channels including: SMS, Voice, and Webchat with shared memory using [Twilio Agent Connect (TAC)](https://www.twilio.com/docs/conversations/agent-connect), [OpenAI](https://developers.openai.com/api/reference/responses/overview), and FastAPI.

## Step: Prerequisites 

Make sure you have your accounts and local tools ready before we start the workshop:

1. [Python 3.10](https://www.python.org/downloads/) or newer — already installed if you are reading this in the browser.
2. [OpenAI API key](https://platform.openai.com/api-keys) — create one at platform.openai.com.
3. [ngrok](https://ngrok.com) or another HTTPS tunnel — needs to be installed and able to forward to port 8000.
